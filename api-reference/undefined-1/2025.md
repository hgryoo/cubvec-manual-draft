# 2025

이 문서는 2025년 개발 내용을 기반으로, 사용자통합 테스트 시나리오를 기술한다.

소스코드 빌드로부터 예제 데이터를 로드하고 인덱스 조회까지의 예시를 포함한다.

#### CUBVEC 소스코드로부터  빌드하기

기본적으로 CUBRID를 빌드하는 방법과 동일하다. 벡터 거리 연산자와 함수에서 SIMD를 통해 더 좋은 성능을 위해 해당 환경의 CPU에 최적화하여 가능한 명령어셋을 사용하는 코드를 컴파일러가 생성하도록 하기 위해서 직접 빌드할 필요가 있다.

<pre><code>-- cubrid 가져오기
<strong>git clone https://github.com/CUBRID/cubrid/
</strong><strong>
</strong>-- 브랜치 전환하기
git checkout cubvec/cubvec
</code></pre>

CUBRID를 빌드하기 위해 서드파티 라이브러리를 설치할 필요가 있다. 다음은 cubrid 브랜치의 docs의 일부 내용을 발췌했으며, Ubuntu 24.04 버전을 기준으로 설치 스크립트를 제공한다.

> 설치를  위해 sudo 권한이 필요하다.

```
DEBIAN_FRONTEND=noninteractive apt-get -y install tzdata
apt-get update && apt-get install -y software-properties-common && add-apt-repository ppa:ubuntu-toolchain-r/test && apt-get update
apt-get install -y --no-install-recommends build-essential
apt-get install -y --no-install-recommends wget git cmake systemtap systemtap-sdt-dev flex ninja-build
apt-get install -y --no-install-recommends gcc-9 g++-9 && \
    update-alternatives --install /usr/bin/gcc gcc /usr/bin/gcc-9 90 && \
    update-alternatives --install /usr/bin/g++ g++ /usr/bin/g++-9 90
apt-get install -y --no-install-recommends libopenblas-dev liblapack-dev
apt-get install -y --no-install-recommends openjdk-8-jdk
apt-get install -y --no-install-recommends ncurses-dev
apt-get install -y --no-install-recommends systemtap-sdt-dev
apt-get install -y --no-install-recommends libelf-dev
apt-get install -y --no-install-recommends libtool m4 curl
apt-get install -y --no-install-recommends libfl-dev # flexlexer.h

# Install Bison 3.0.5 manually
ENV BISON_VERSION=3.0.5
RUN curl -L https://ftp.gnu.org/gnu/bison/bison-${BISON_VERSION}.tar.gz | tar xzvf - && \
    cd bison-${BISON_VERSION} && \
    ./configure --prefix=/usr && \
    make -j$(nproc) && \
    make install && \
    cd .. && \
    rm -rf bison-${BISON_VERSION}
    
ENV DEBIAN_FRONTEND=noninteractive
ENV CMAKE_VERSION=3.26.3

# Download and install CMake
RUN curl -L https://github.com/Kitware/CMake/releases/download/v${CMAKE_VERSION}/cmake-${CMAKE_VERSION}-linux-x86_64.tar.gz | \
    tar --strip-components=1 -xz -C /usr --wildcards 'cmake-*/*'
```

다음으로 빌드를 수행한다. 이 때 SIMD의 AVX2 명령어셋을 활성화하도록 PRESET을 설정한다. \
HOME 디렉토리의 cubrid\_install 에 설치가 되도록 설정되어 있으며, 변경 가능하다.

```
PRESET=release_avx2 && \
    BUILD_DIR="build_preset_${PRESET}" && \
    INSTALL_DIR="~/cubrid_install" && \
    git fetch --all && \
    git checkout ${BRANCH} && \
    git submodule update --init cubrid-cci && \
    cmake --preset "$PRESET" && \
    cmake --build --preset "$PRESET" -j$(nproc) && \
    cmake --install "$BUILD_DIR" --prefix "$INSTALL_DIR"
```

설치한 CUBRID의 경로에 맞게 다음과 같이 환경변수를 설정한다.

```
export CUBRID=~/cubrid_install
export CUBRID_DATABASES=$CUBRID/databases
export LD_LIBRARY_PATH=$CUBRID/lib:$CUBRID/cci/lib:$LD_LIBRARY_PATH
export SHLIB_PATH=$LD_LIBRARY_PATH
export LIBPATH=$LD_LIBRARY_PATH
export PATH=$CUBRID/bin:$PATH
```

#### CUBRID 서버 시작

```
cubrid server start
```



#### ann-benchmarks 레포지토리의 HDF5 로드하기

ann-benchmarks에는 메모리에 로드할 수 있는 수준의 벤치마크용 예시 벡터 데이터셋이 HDF5로 준비되어 있다. 이 데이터를 로드하기 위해서 CUBRID의 loaddb 포맷으로 변환이 필요하다.

다음의 명령어로 HDF5 파일을 로드한다.

```
cubrid loaddb -h <hdf5_file_path> <db_name>
```

그 결과로, 다음과 같이 스키마 파일과 오브젝트 파일이 생성된다.

```
-- <hdf5_file_name>.schema
<hdf5_file_name>_train ([id] BIGINT PRIMARY KEY, [vec] VECTOR (<dimension>))
<hdf5_file_name>_test ([id] BIGINT PRIMARY KEY, [vec] VECTOR (<dimension>))
<hdf5_file_name>_answer ([id] BIGINT, [neighbor_id] BIGINT, [neighbor_dist] DOUBLE)

CREATE VECTOR INDEX ...
```

```
-- <hdf5_file_name>.object
%id <hdf5_file_name>_train 1
%id <hdf5_file_name>_test 2
%id <hdf5_file_name>_answer 3
%class <hdf5_file_name>_train ([id], [vec])
<데이터 문자열> e.g.) 0 '[0.1, 0.1, 0.2 ... ]'
%class <hdf5_file_name>_test ([id], [vec])
<데이터 문자열> e.g.) 0 '[0.1, 0.1, 0.2 ... ]'
%class <hdf5_file_name>_answer ([id], [neighbor_id], [neighbor_dist])
...
```

다음으로 loaddb의 -s, -d 옵션을 이용하여 데이터베이스에 로드할 수 있다. \
다음은 glove\_25\_angular  데이터를 로드하는 방법이다.

<pre><code>wget http://ann-benchmarks.com/glove-25-angular.hdf5
<strong>cubrid loaddb -C -h glove-25-angular.hdf5 demodb
</strong>cubrid loaddb -C -s glove_25_angular_schema -d glove_25_angular_object -u dba demodb
</code></pre>

#### 벡터 인덱스 생성하기

로드한 데이터에 대해서 벡터 인덱스를 생성하면, 힙 테이블로부터 배치 방법을 사용하여 더 빠르게 HNSW 인덱스를 로드할 수 있다.

<pre><code><strong>csql -u dba demodb -c "CREATE VECTOR INDEX embedding_hnsw_idx \
</strong>ON glove_25_angular_train (vec COSINE) \
WITH (M = 16, ef_construction = 64);"
</code></pre>

#### 벡터 검색 하기

```
-- test 테이블로부터 vec 가져오기
set @a = (SELECT vec FROM glove_25_angular_test LIMIT 1);

-- K-ANN 검색
SELECT id, vec <c> @a AS dist FROM glove_25_angular_train
ORDER BY vec <c> @a
LIMIT 10;
```
